# VoidPvP — fast crits

Плагин для Bedrock-сервера VoidPE: убирает задержку атаки, даёт крит на удар в прыжке
(в том числе в спринте) и снимает неуязвимость между ударами — «тап-тап» проходит полностью.

## Что делает

| Функция | Как реализовано | Ключ конфига |
|---|---|---|
| Нет задержки атаки | базовое значение атрибута `ATTACK_SPEED` поднимается до `attack-speed.value` (1024) — удар всегда наносит полный урон, бить можно так часто, как успеваешь | `attack-speed.enabled`, `attack-speed.value` |
| Крит в прыжке | в `EntityDamageByEntityEvent` урон умножается на `crits.multiplier` (1.5), если атакующий в воздухе или падает. В ваниле спринт-прыжок крит НЕ даёт (спринт отменяет крит) — здесь даёт | `crits.while-airborne` |
| Крит всегда | режим «всё криты», даже с земли | `crits.always` |
| Криты без кд | никаких ограничений по времени и сериям: крит считается на каждом ударе, где выполнено условие | — |
| Нет неуязвимости | после удара игрока по живому существу через тик сбрасывается `noDamageTicks` (ванильные 0.5 с), поэтому следующий тап тоже наносит урон | `no-invulnerability.enabled` |
| Частицы и звук крита | шлются с сервера (Bedrock-клиент сам их не рисует) | `crits.particles`, `crits.sound` |

Ванильный крит (падение без спринта) не удваивается: сервер уже умножил урон на 1.5,
плагин это распознаёт и пропускает удар.

Удары стрелами, взрывы, огонь и размашистый удар (sweep) не затрагиваются.

## Установка

1. `VoidPvP-1.0.0.jar` → в `plugins/`
2. Полный перезапуск сервера (не reload)
3. Настройки: `plugins/VoidPvP/config.yml`, после правок — `/voidpvp reload`

Готовый эталонный конфиг лежит в репозитории: `configs/VoidPvP-config.yml`.

## Команда

```
/voidpvp            — статус (алиасы: /fastcrits, /vpvp)
/voidpvp status     — то же
/voidpvp reload     — перечитать config.yml (право voidpvp.admin)
```

## Права

| Право | По умолчанию | Что даёт |
|---|---|---|
| `voidpvp.use` | всем | команда `/voidpvp` |
| `voidpvp.admin` | оператор | `/voidpvp reload` |
| `voidpvp.off` | — | отключает fast crits у конкретного игрока (перебивает `permissions.require`) |

Если нужно выдавать систему только по привилегии: `permissions.require: "voidpvp.fastcrits"`
и выдать группам `lp group <группа> permission set voidpvp.fastcrits true`.

## Совместимость

* **VoidCombat** — не конфликтует: тот отвечает за PvP-метку и кулдауны расходников.
* **VoidAntiCheat** — лимиты CPS (`autoclicker-cps: 24`, `autoclicker-touch-cps: 27`)
  рассчитаны на обычную скорость удара. При спаме «тап-тап» античит может выдавать
  AutoClicker. Если это мешает — поднять лимиты в конфиге VoidAntiCheat или выдать
  игрокам обход, а не отключать проверку целиком.

## Сборка

```bash
cd VoidPvP
mvn -B -DskipTests package     # → target/VoidPvP-1.0.0.jar
```

Собирается Maven-шагом в `.github/workflows/build.yml` и попадает в релиз
(`release.yml`) как отдельный ассет.
